# Customer Shopping Behavior Analysis

## Overview
An end-to-end data analytics project analyzing 3,900 customer purchases to understand shopping patterns, product preferences, customer segments, and subscription behavior.

## Tools Used
- Python (Pandas)
- SQL
- PostgreSQL
- Power BI

## Project Workflow
- **Data Cleaning:** Handled missing values, standardized column names, and performed feature engineering using Python and Pandas.
- **SQL Analysis:** Used PostgreSQL to analyze revenue, customer segments, product ratings, discounts, shipping types, and subscription behavior.
- **Dashboard:** Built an interactive Power BI dashboard to visualize key insights.
- **Reporting:** Prepared a detailed report with findings and business recommendations.

## Key Insights
- Compared revenue generated by male and female customers.
- Analyzed subscribers versus non-subscribers.
- Identified top-rated and most-purchased products.
- Segmented customers into New, Returning, and Loyal groups.
- Examined discount usage, shipping preferences, and age-group revenue.

## Business Recommendations
- Promote subscription benefits.
- Introduce customer loyalty programs.
- Optimize discount strategies.
- Highlight top-rated and best-selling products.
- Target high-revenue customer segments.
